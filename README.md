A deterministic program that writes the one line a smart fridge would text
its owner at 3am, to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> I ran a self-diagnostic at 3AM. Verdict: I'm fine. You're the one standing here in the dark, pretending the light inside me is a nightlight
